# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |

## 多房隔离口径（关键设计取舍，全局唯一）

本系统选定 **甲：每房独立水位**，并由「扫描范围徽标」把口径钉死在徽标上：

- 水位表主键＝房间键；一房事件只抬本房水位，关窗扫描只扫本房开启窗，他房窗不受影响；
- 对照口径乙（全局统一水位，任一房事件抬全局水位、跨房关到期窗）**未采用**，禁止宣称全局水位却只关本房。
- 可区分判据：A/B 两房均有窗止可被越过的开启窗、只推 A 房事件后——甲：仅 A 关、B 仍开；乙：A/B 到期窗皆关。
- 只读接口 `GET /api/房级水位`：返回隔离口径、水位主键、扫描范围、每房 valid 与徽标核证（徽标范围/世代/水位值）。
- 并发：装载整批 `BEGIN IMMEDIATE` 串行化 + 水位按房键条件更新（WAL/busy_timeout），杜绝「A 房水位写到 B 房」半截串房；测试见 `backend/tests/test_房级水位.py`。

### 扫描范围徽标（同票四要素，硬约束）

关键设计取舍（全局只贯彻一种）选定 **「事件房键钉本房徽标」**；对照项「全局切换工单扩权」**未采用**：

- 每次房级抬升成功，必须在**同一事务同票**把本房徽标刷新为本房范围，四要素齐备：
  范围=本房、房键=本房键、水位值=本房水位行当前值、徽标世代按房单调递增；
  即使历史存在陈旧全局徽标也必须刷回本房，禁止保留或写回全局徽标；
- 关窗扫描只能扫徽标声明的范围：徽标缺失/范围非本房/房键与水位行分叉/水位值陈旧即
  **fail-closed 拒绝扫描**，不回退全局、不带病关窗；
- 徽标刷新失败不得吞异常：本房水位已写也随整票回滚（装载事务 `rollback`），杜绝半截态；
- 硬约束三条：禁止抬升成功徽标未刷新；禁止徽标范围与水位行房键分叉仍关窗；禁止串房写水位行。
- 全局切换工单：`POST /api/全局切换工单` 仅登记审计（表 `全局切换工单`），**任何齐套工单都不扩权**——
  登记后再抬升，甲仍不关他房、徽标仍写本房；乙口径在本系统无生效路径。
- 核证只读接口 `GET /api/核证/扫描徽标[?房间键=]`：返回设计取舍、每房徽标四要素核证（valid/无效原因）、
  徽标追加式历史与工单审计行；纯 SELECT 不写库。测试见 `backend/tests/test_扫描范围徽标.py`。
